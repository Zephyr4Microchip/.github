# Welcome to Zephyr4Microchip

Zephyr4Microchip brings the [Zephyr RTOS](https://zephyrproject.org/) ecosystem to Microchip devices, providing a scalable, optimized, and secure real-time operating system for Microchip microcontrollers and microprocessors.

This organization hosts **Microchip zSDK**. It is a framework that delivers a minimally customized Zephyr distribution, with downstream modules and Microchip libraries. 

## Getting Started
See the [Getting Started Guide](https://github.com/Zephyr4Microchip/microchip-zsdk/blob/main/doc/Getting_Started_with_Microchip_zSDK.md) documentation to start developing with Microchip zSDK.

## Microchip zSDK Repositories
- [microchip-zsdk](https://github.com/Zephyr4Microchip/microchip-zsdk) - Microchip zSDK
- [microchip-zephyr](https://github.com/Zephyr4Microchip/microchip-zephyr) - Microchip downstream of Zephyr
- [microchip-hal](https://github.com/Zephyr4Microchip/microchip-hal) - Microchip downstream HAL module
