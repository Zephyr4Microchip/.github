# [Welcome to Zephyr4Microchip](https://www.microchip.com/en-us/tools-resources/develop/zephyr)

Zephyr4Microchip brings the [Zephyr RTOS](https://zephyrproject.org/) ecosystem to Microchip devices, providing a scalable, optimized, and secure real-time operating system for Microchip microcontrollers and microprocessors.
